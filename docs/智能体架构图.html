稳定段
角色设定 + 规则 0~19（数据口径、引用规范、写库边界…），内容固定并打指纹，便于模型侧前缀缓存。
动态段

写库闸门：「写日志 / 存资料库」类工具默认 fail-closed —— 只有用户明确表达"写入 / 保存"意图才放行，避免静默写库。

ReAct
循环
Loop

决策 → 执行 → 回灌 → 判定

单飞锁防重入 · 停止令牌可中断
STEP 1
模型决策
携带按意图挑出的工具集请求模型；兼容 tool_calls 与文本 JSON 两种返回。
→
STEP 2
并行执行
同一轮多个工具 Promise.all 并发；每个工具带超时、只读失败重试一次、只读结果 60s 缓存。
→
STEP 3
结果回灌
结果裁剪（单次 12000 字 / 列表 50 条），失败与 0 命中补"换词/放宽"提示，配对为 tool 消息。
→
STEP 4
完成判定
无工具调用即进入完成度门禁：核对是否真取到数据，再输出答案与本次引用。
↺ 未完成 回到 STEP 1 继续下一轮 —— 上限 15 轮 / 单任务 8 分钟 / 工具总耗时 120 秒 首轮即可收敛时不必调工具
退出：模型给出最终答案 退出：达到 15 轮 退出：8 分钟墙钟耗尽 退出：用户点停止 退出：连续重复同一调用（先反思跳过，再终止） 退出：工具预算用尽（回灌"未执行"并催结论）

元数据单一注册表（增删只改两处）
  • kind：read / write / export / net —— 决定能否重试与缓存
  • timeout：默认 15s，导出类 30s
  • whenNotToUse：显式写"何时不该用"，并入 description 供模型判断
  • purpose：用于步骤卡与透明日志，避免只显示"调用工具"
双向审计：注册表与工具定义互相校验，防止改名漏改导致元数据漂移。

Memory

任务记忆 + 反思 + 跨任务画像

不是自进化，是 Reflexion 式经验复用
任务记忆
本机 IndexedDB 存最近 30 条 / 30 天：意图、计划、每步工具与耗时、产出、用量、反思结论。
三通道注入
最近 3 条任务摘要；与本次意图相关的任务（2-gram 相似度 ≥0.28，最多 2 条）；最近 3 条反思经验。
任务后反思
结束后异步调一次模型，产出「问题 / 建议 / 短板」，回写同一条任务记录，不新建表。
经验是否真生效
下次任务若避开既有短板记 helped，否则记 ignored，形成可用性统计而非"反思了就算完"。
跨任务画像
从历史任务沉淀关注单位、关键词、问题性质、时间范围，注入为偏好，减少重复交代。
自主盯控（独立）
5 分钟轮询台账/规章/日志/电话/备忘；首次建基线，之后按增量或阈值判定，6 小时冷却防打扰。

模型通道

上下文治理
消息超 12 条才裁剪：最近 2 条助手正文保完整，更早正文留头尾；工具结果只保最近 6 条。
可观测
规划 / 思考 / 工具开始 / 进度心跳 / 工具完成 / 答案六类事件，逐步卡片可见。
离线边界
模型推理与联网检索需联网；其余读写全部本机，门禁拦截额外外联。
