🔧 大模型 API 配置
📌 配置用途
本系统的智能助手（智能对话 / 智能体 / 智能对规 / 智能写作 / 风险研判）均依赖大模型 API 生成回答。未配置 API Key 时无法使用任何 AI 功能；配置后所有模块统一调用「当前使用模型」，切换立即对全部模块生效。
🛠️ 配置步骤
1. 在模型厂商官网注册账号并获取 API Key（如 DeepSeek、阿里通义、智谱 GLM、OpenAI 等）；
2. 点击右上「＋ 新增模型」，填写 名称 / API 地址 / 模型名称 / API Key；
3. 点击「保存模型」，并点「设为当前」使其成为默认模型；
4. 需要实时联网检索时，可在编辑表单中勾选「🌐 联网搜索」。
