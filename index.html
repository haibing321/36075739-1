💡 为什么需要配置 API？
智能助手（AI对话、智能对规、智能写作、风险研判）需调用大语言模型处理。 配置后即可使用全部 AI 功能，不配置则只能使用豆包网页版。
支持 OpenAI 兼容格式，可从下拉列表选择或手动输入
2026年6月最新模型，可从下拉列表选择或手动输入
请前往模型平台获取（如 platform.deepseek.com）
📘 如何注册并获取 API Key？

推荐使用 DeepSeek（性价比高，国内可用）：

  1. 访问 https://platform.deepseek.com/ 注册账号。
  2. 登录后进入「API Keys」页面，点击「创建 API Key」。
  3. 复制生成的 Key（格式：sk-xxxxxxxx），粘贴到上方输入框。
  4. API 地址和模型名称保持默认，点击「保存」即可。

其他兼容平台：

  • OpenAI: https://api.openai.com/v1/chat/completions，模型 gpt-3.5-turbo
  • 通义千问: https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions，模型 qwen-turbo
  • 智谱: https://open.bigmodel.cn/api/paas/v4/chat/completions，模型 glm-4

💡 配置保存后立即生效。如需切回豆包网页版，点击「清除配置」。

💡 保存后立即启用本地智能助手，清除配置则返回豆包网页版。
