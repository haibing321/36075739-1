============================================================
 安监智能辅助系统 · 麒麟（Linux）运行说明
============================================================
适用：U 盘上以「安监智能辅助系统_vX.XX_日期」命名的版本目录
      （目录里应有 index.html / src / icons / start-linux.sh）

------------------------------------------------------------
一、推荐：一次配置，以后双击图标启动（永久"一键"）
------------------------------------------------------------
 1) 插上 U 盘，打开本版本目录；
 2) 在本目录打开终端：
      · 文件管理器里：空白处右键 →「在终端中打开」
      · 或右键 start-linux.sh →「在终端中打开」
 3) 输入下面这一行，回车（只需做这一次）：
        bash start-linux.sh --install
 4) 以后双击桌面上的「安监智能辅助系统」图标即可启动（应用菜单里也有）。
    · 会自己弹出终端窗口 —— 关闭该窗口 = 停止服务
    · 程序已复制到本机，之后不插 U 盘也能用

------------------------------------------------------------
二、不安装，直接用（每次输一行命令）
------------------------------------------------------------
 按上面第 2 步打开终端，输入：
        bash start-linux.sh
 自动：挑空闲端口（8788 起）→ 起"纯本机"服务 → 浏览器应用窗口打开 → 关窗口即停。

------------------------------------------------------------
三、这台麒麟能上外网时（最省事，U 盘都不用插）
------------------------------------------------------------
 浏览器直接打开（三个站内容一致，固定用一个）：
        https://haibing321.github.io/36075739-3/
 若浏览器是 Chromium 内核（Chrome / Edge / 奇安信 / 麒麟浏览器等），
 还能在地址栏右侧点「安装」，做成桌面应用（断网也能用）。

------------------------------------------------------------
四、常见问题
------------------------------------------------------------
 1. 双击 start-linux.sh 没反应？
    U 盘（FAT/exFAT）没有 Linux 执行权限，属正常 —— 用上面的终端命令即可。
    若双击弹出「运行 / 在终端中运行 / 显示」对话框，选"在终端中运行"也行。
 2. 提示找不到 python3？
    终端执行：  sudo apt install -y python3      （麒麟/统信为 deb 系）
    脚本只用系统自带的 python3 当服务端，不需要装其它东西。
 3. 弹出的是普通浏览器窗口（带地址栏）？
    说明本机没装 Chromium 内核浏览器，自动退化为 Firefox/默认浏览器，功能不受影响。
 4. 打开后发现自己以前录的数据没了？
    数据保存在"每台电脑各自的浏览器"里，不随 U 盘走。
    请先在原来那台电脑用系统内的「导出数据 / 备份」，把文件拷过来后「导入」。
 5. 想卸载本机安装？
    删除目录   ~/.local/share/anjian-helper
    与文件     ~/.local/share/applications/anjian-helper.desktop
    （桌面上的那个图标一并删除即可）
 6. 目录里少了文件 / 启动报错，怀疑被杀毒软件清理？
    先做完整性校验（纯本地，不联网、不写文件）：
        cd 版本目录
        sha256sum -c SHA256SUMS.txt
    输出里每个文件会显示 OK 或 FAILED；缺失的文件从原始包补回即可。
    Windows 上对应的是双击「校验文件完整性.bat」，说明见「安全说明（先读我）.txt」。

------------------------------------------------------------
五、小贴士
------------------------------------------------------------
 · 服务脚本为什么叫 start-linux.sh 这种英文名：
   终端里好输入，且不受 U 盘无执行权限、中文输入法的影响。
 · Windows 电脑：双击同目录的「启动（双击运行）.bat」即可。
