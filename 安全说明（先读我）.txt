 安监智能辅助系统 · 安全说明（请先读我）
============================================================

一、这份目录是什么
------------------------------------------------------------
  · 一个纯静态网页应用（HTML + CSS + JavaScript + 图片）。
  · 没有任何 exe / dll / 安装程序；不写注册表、不开机自启、不驻留后台。
  · 业务数据只存在本机浏览器的数据库里（IndexedDB / localStorage），
    不会上传到任何服务器。
  · 只有两种情况会联网：
      1) 点「设置 → 检查更新」时，读取本站点的 version.json；
      2) 使用 AI 功能时，访问你自己配置的大模型接口（密钥也只存本机）。

二、为什么可能被当成“病毒”
------------------------------------------------------------
  1. 整个应用由较大的 index.html 加大量 JavaScript 组成，并且具备
     “在浏览器里生成文件并下载”的能力（导出 DOCX、备份 ZIP）——
     这正是杀毒软件启发式规则最容易误判的形态（HTML/Downloader 一类）。
  2. 启动脚本调用 Windows 自带的 PowerShell，起一个“仅本机可访问”的
     网页服务（127.0.0.1），脚本类文件通常会被安全软件重点扫描。
  3. 如果是从网上下载的压缩包解压出来的，文件会带“来自 Internet”标记
     （Mark of the Web），系统和杀软会更严格，个别会直接删除。
  以上均属误报，不代表文件被感染。

三、文件被删了怎么办（Windows）
------------------------------------------------------------
  1) 打开杀毒软件的「隔离区 / 恢复区」，找到被隔离的文件，选择“恢复”。
  2) 把本版本目录加入信任：
       · Windows 安全中心：病毒和威胁防护 → 管理设置 → 排除项 → 添加文件夹
       · 360 / 火绒 / 单位 EDR：在“信任区 / 白名单”里添加本目录
  3) 双击本目录的「校验文件完整性.bat」，全部通过后再启动。
  4) 若来自压缩包，先“解除锁定”：
       在该文件上右键 → 属性 → 勾选“解除锁定” → 确定；
       或在 PowerShell 中对整个目录执行：
         Get-ChildItem -Recurse | Unblock-File

四、怎么确认文件没被改动
------------------------------------------------------------
  · 双击「校验文件完整性.bat」，它会逐个比对 SHA256SUMS.txt。
  · 手工校验单个文件（Windows 自带命令）：
       certutil -hashfile index.html SHA256
    输出应与 SHA256SUMS.txt 中对应行一致。
  · 麒麟 / Linux：
       sha256sum -c SHA256SUMS.txt

五、正常启动方式（务必按这个来）
------------------------------------------------------------
  · Windows：双击「启动（双击运行）.bat」
      → 起一个仅本机可访问的本地服务，再用浏览器应用窗口打开；关窗口即停。
  · 麒麟 / 统信：在终端执行   bash start-linux.sh
      （详见「启动说明（麒麟Linux）.txt」）
  · 不要直接双击 index.html：
      以本地文件方式打开时，浏览器会禁用 Service Worker，
      离线能力与“安装为应用”都会失效（页面本身仍可浏览）。

六、给单位安全审查的一句话说明
------------------------------------------------------------
  本软件为纯前端离线应用：无服务端、无自启、无后台进程、无数据回传；
  联网仅限“检查更新”与“用户自行配置的 AI 接口”。
  如需审计，可提供全部源码（HTML / CSS / JS）与 SHA256 校验清单。
